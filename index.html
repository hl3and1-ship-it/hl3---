#交付项具体内容验收标准主责
1AI 翻译后端接通配置 OpenAI 兼容端点 + Key（通义/智谱/DeepSeek 或 OpenAI），让 tabLlm「翻译此语言」出结果选目标语言点 AI 翻译，译文正确回填，无 401/超时开发 + IT
2翻译管理闭环手动编辑 + JSON 导入/导出 + tid 锚点 + 英文母版映射导入既有翻译 JSON 后画布文本更新；导出 JSON 可再导入开发
3表格导入一键翻译确定来源（飞书 URL 或本地 xlsx/csv）→ 解析为翻译表 → 一键调用 LLM 批量翻译补全缺失项导入表格点「一键翻译」，所有未译语言批量补全开发
416 国语言自动排版验证 autoLayout 按 16 国展开内页可用点自动排版，内页按 16 语生成独立页，数量正确开发
5真机测试框架Playwright 覆盖翻译主流程（翻译→导入→自动排版）主流程有自动化用例 + 截图回归开发 + 测试
✓ Phase 1 完成判据： 运营/翻译同事导入含 tid 的表格 → 一键翻译补全 16 国语言 → 点自动排版生成多语页面，全过程无阻断。
